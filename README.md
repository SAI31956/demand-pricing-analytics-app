# Demand Analytics Streamlit App

This project demonstrates an end-to-end analytics pipeline following:

Observe → Predict → Forecast

## Features
- Descriptive Analytics (EDA)
- Demand Prediction using Regression
- Time Series Forecasting (ARIMA)
- Pricing & Revenue Insights

## Tech Stack
- Python
- Streamlit
- Pandas, NumPy
- Plotly
- Scikit-learn
- Statsmodels

## How to Run
```bash
streamlit run app.py
